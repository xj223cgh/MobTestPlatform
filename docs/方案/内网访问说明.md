# 内网访问说明

本机运行平台时，同网段同事可通过你的内网 IP 访问。**后端**已监听 `0.0.0.0`（`backend/run.py`），**前端** Vite 已设 `host: '0.0.0.0'`、端口 `8081`，一般无需改代码。

## 防火墙（必做）

放行 **TCP 8081**（前端）、**5000**（后端）。

**图形界面**：Windows 安全中心 → 防火墙 → 高级设置 → 入站规则 → 新建规则 → 端口 → TCP → `8081,5000` → 允许连接。

**PowerShell（管理员）**：

```powershell
New-NetFirewallRule -DisplayName "MobTestPlatform" -Direction Inbound -Protocol TCP -LocalPort 8081,5000 -Action Allow
```

## 访问方式

1. 本机执行 `ipconfig`，取以太网/WLAN 的 **IPv4**（如 `192.168.1.100`）。
2. 同事浏览器打开：`http://你的内网IP:8081`（本机需已 `python start.py`）。
3. 前端代理会转发到本机后端，同事无需单独配置代理。

若 DHCP 导致 IP 变动，可在路由器做静态分配或在网卡上设固定 IP（避免冲突）。

## 常见问题

| 现象 | 处理 |
|------|------|
| 打不开页面 | 检查防火墙是否放行 8081、5000 |
| 页面能开、接口失败 | 确认 5000 已放行 |
| 自己能访问、别人不能 | 确认同一网段/路由可达 |
| 曾能访问现不能 | 本机 IP 是否变化 |

若公司内网网段特殊，可在 `backend/.env` 的 `CORS_ORIGINS` 中追加前端访问来源（逗号分隔）后重启后端。
