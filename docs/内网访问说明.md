# 内网访问说明

当项目部署在你本机，且设备已连接公司内网时，同网段的同事可以通过你的电脑访问该网站。

## 一、本机需要做的配置

### 1. 确认服务监听地址（已就绪）

- **后端**：已绑定 `0.0.0.0`（`backend/run.py`），会监听所有网卡。
- **前端**：Vite 已配置 `host: '0.0.0.0'`（`frontend/vite.config.js`），端口为 `8081`。

无需再改代码即可被内网访问。

### 2. 放行防火墙端口（必做）

其他电脑要连到你本机，需要在本机 **Windows 防火墙** 中放行以下端口：

| 端口 | 用途     |
|------|----------|
| 8081 | 前端页面 |
| 5000 | 后端 API |

**操作步骤：**

1. 打开 **Windows 安全中心** → **防火墙和网络保护** → **高级设置**。
2. 左侧选 **入站规则** → 右侧 **新建规则**。
3. 选择 **端口** → 下一步 → 选 **TCP**，特定本地端口填 `8081,5000` → 下一步。
4. 选择 **允许连接** → 下一步 → 全选（域、专用、公用）→ 下一步。
5. 名称填例如「MobTestPlatform 内网访问」→ 完成。

也可用管理员 PowerShell 一条命令添加：

```powershell
New-NetFirewallRule -DisplayName "MobTestPlatform" -Direction Inbound -Protocol TCP -LocalPort 8081,5000 -Action Allow
```

### 3. 查看本机内网 IP

在 **命令提示符** 或 **PowerShell** 中执行：

```bash
ipconfig
```

在 **以太网** 或 **WLAN** 适配器下找到 **IPv4 地址**，例如：`192.168.1.100`。

---

## 二、其他人如何访问

1. 确保同事和你在 **同一公司内网**（同一网段或路由可达）。
2. 在你本机已启动项目（运行 `python start.py`）且防火墙已放行的情况下，同事在浏览器中访问：

   ```text
   http://你的内网IP:8081
   ```

   例如：`http://192.168.1.100:8081`

3. 前端会通过你本机的 Vite 代理访问后端，无需同事做任何代理或 hosts 配置。

---

## 三、可选：固定你的内网 IP（推荐）

若内网使用 DHCP，本机 IP 可能会变，别人保存的地址会失效。可考虑：

- 在路由器或公司网络管理中为本机 MAC 地址绑定固定 IP，或  
- 在 Windows 网卡属性里为「IPv4」设置固定地址（需与公司网段一致，避免冲突）。

---

## 四、故障排查

| 现象                 | 可能原因           | 处理建议                           |
|----------------------|--------------------|------------------------------------|
| 同事打不开页面       | 防火墙未放行       | 按上面步骤添加入站规则放行 8081/5000 |
| 页面能开，接口报错   | 仅放了 8081        | 同时放行 5000 端口                 |
| 自己能访问别人不能   | 不在同一网段       | 确认连的是同一内网/WiFi            |
| 之前能访问现在不能   | 本机 IP 变了       | 让同事改用当前 `ipconfig` 的 IP 访问 |

后端已配置 CORS 允许内网网段（如 `192.168.x.x`、`10.x.x.x`），一般无需再改。若公司使用其他内网网段，可在 `backend/.env` 中增加：

```env
# 在原有 CORS_ORIGINS 后追加，逗号分隔
CORS_ORIGINS=http://localhost:3000,http://localhost:8080,http://你的IP:8081
```

保存后重启后端即可。
