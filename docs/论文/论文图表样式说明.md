# 论文图表样式说明

为保证论文中所有 Mermaid 图字体与背景风格一致（**黑色字体、无背景/浅色背景**），已在各章 Mermaid 代码块首行加入统一主题配置。

## 1. 已采用的配置

所有 Mermaid 图均使用以下 **init** 行（紧接在 ` ```mermaid ` 下一行）：

```text
%%{init: {'theme': 'base', 'themeVariables': { 'primaryTextColor':'#000', 'secondaryTextColor':'#000', 'tertiaryTextColor':'#000', 'primaryBorderColor':'#333', 'lineColor':'#333', 'mainBkg':'#fff', 'secondBkg':'#f9f9f9'}}}%%
```

含义简要说明：

| 变量 | 取值 | 作用 |
|------|------|------|
| primaryTextColor / secondaryTextColor / tertiaryTextColor | #000 | 节点内文字为黑色 |
| primaryBorderColor / lineColor | #333 | 边框与连线为深灰/黑 |
| mainBkg | #fff | 节点主背景为白色 |
| secondBkg | #f9f9f9 | 子图（subgraph）背景为浅灰 |

**图案/节点间距（可选）：** 若某张图需要加大节点之间或节点与边框的间隔，可在同一 `themeVariables` 中增加：

| 变量 | 建议范围 | 作用 |
|------|----------|------|
| nodeTextMargin | 10～20（默认约 10） | 节点内文字与边框的内边距，数值越大节点框越大，视觉上节点间距更疏 |
| padding | 12～25 | 整图外边距，数值越大图四周留白越多 |

图 4-1 已示例使用 `'nodeTextMargin': 14, 'padding': 18`，可按需改大或改小。

## 2. 新增图表时如何保持一致

**每次新增一个 Mermaid 图时**，在 ` ```mermaid ` 后**第一行**加上上述整行 `%%{init: ...}%%`，再写 flowchart / erDiagram 等代码。例如：

```mermaid
%%{init: {'theme': 'base', 'themeVariables': { 'primaryTextColor':'#000', 'secondaryTextColor':'#000', 'tertiaryTextColor':'#000', 'primaryBorderColor':'#333', 'lineColor':'#333', 'mainBkg':'#fff', 'secondBkg':'#f9f9f9'}}}%%
flowchart LR
    A[节点A] --> B[节点B]
```

## 4. 导出为图片时

在 [Mermaid Live Editor](https://mermaid.live) 中粘贴带上述 init 的代码后，可直接导出 PNG/SVG。若在 Word 中通过插件渲染，请确认插件支持 `%%{init:...}%%`（多数支持）。若某工具不支持主题配置，可先在 Mermaid Live 中导出图片，再插入论文。
