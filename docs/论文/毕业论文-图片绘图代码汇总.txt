---------- 图 5-1  用户登录时序图 ----------
位置：第五章 详细设计 → 5.1 用户与权限模块详细设计

```mermaid
sequenceDiagram
    participant 用户
    participant 前端
    participant 后端
    participant 数据库

    用户->>前端: 输入用户名、密码并提交
    前端->>后端: 提交登录请求 (POST /login)
    后端->>数据库: 查询用户信息 (User)
    数据库-->>后端: 用户记录
    后端->>后端: 校验密码、锁定与激活状态 (check_password)
    后端->>数据库: 查询会话配置 (SystemSetting)
    数据库-->>后端: 配置信息
    后端->>后端: 创建会话 (login_user)
    后端->>数据库: 查询角色权限 (get_user_permission_codes)
    数据库-->>后端: 权限列表
    后端-->>前端: 返回用户信息与权限
    前端-->>用户: 登录成功，跳转首页
```


---------- 图 5-2  获取当前用户与权限校验时序图 ----------
位置：第五章 详细设计 → 5.1 用户与权限模块详细设计（图 5-1 之后）

```mermaid
sequenceDiagram
    participant 前端
    participant 后端
    participant 数据库

    前端->>后端: 获取当前用户或权限 (GET /current-user、/permissions)
    后端->>后端: 从会话获取 current_user (Flask-Login)
    后端->>数据库: 查询用户信息、角色权限
    数据库-->>后端: 用户、权限列表
    后端-->>前端: 返回用户与权限

    前端->>后端: 请求受保护接口（如用户管理）
    后端->>后端: 鉴权 (@login_required、权限埋点)
    alt 无权限
        后端-->>前端: 403 无权限
    else 有权限
        后端->>数据库: 执行业务查询/更新
        后端-->>前端: 返回业务数据
    end
```

```mermaid
        后端-->>前端: 409 请刷新后重试或强制覆盖
    end

    后端-->>前端: 返回 suite_id、case_count、mindmap_version
    前端-->>用户: 保存成功
```
