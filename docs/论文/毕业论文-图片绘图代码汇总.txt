【图片渲染说明】如何把本文档中的代码变成可插入论文的图片
--------------------------------------------------------------------------------
本文件为纯文本代码汇总，需用下方方式之一渲染后再插入 Word/论文。

一、Mermaid 图（图 3-1、3-3、图 4-x、图 6-1 等）
  · 复制对应 ```mermaid 与 ``` 之间的整段代码（不含 ```mermaid 和 ``` 两行）
  · 打开 https://mermaid.live 粘贴 → 可预览并导出 PNG/SVG
  · 或使用支持 Mermaid 的 Markdown 编辑器（如 Typora、VS Code 装 Mermaid 插件）预览后截图/导出

二、PlantUML 图（图 3-2、图 5-1～5-11）
  · 复制对应 ```plantuml 与 ``` 之间的整段代码（必须包含 @startuml 和 @enduml 两行，不要带 ```plantuml 和 ```）
  · 在线渲染：打开 https://www.plantuml.com/plantuml/uml 粘贴 → 即显示图片 → 右键保存图片或导出 PNG/SVG
  · VS Code 本地渲染：安装扩展 "PlantUML" (jebbs.plantuml)，新建 .puml 文件粘贴同一段代码，按 Alt+D 预览，再右键导出 PNG/SVG
  · 若在线版报错：请确认复制内容从 @startuml 到 @enduml 完整且无多余空行；中文若乱码可尝试用支持 UTF-8 的编辑器复制

三、插入论文
  将导出的 PNG 或 SVG 插入 Word：插入 → 图片 → 选择文件即可。

---------- 图 5-1  用户登录时序图 ----------
位置：第五章 详细设计 → 5.1 用户与权限模块详细设计
说明：使用 PlantUML 绘制，左侧为人物形象（actor），生命线上的条状为激活条（activate/deactivate）。

```plantuml
@startuml 图5-1-用户登录时序图
!theme plain
skinparam sequenceMessageAlign center
skinparam responseMessageBelowArrow true
skinparam SequenceLifeLineBorderColor #333
skinparam SequenceArrowColor #333
skinparam SequenceActorBorderColor #333
skinparam SequenceActivationBackgroundColor #E8E8E8
skinparam SequenceActivationBorderColor #333
hide footbox

actor "用户" as user
participant "前端" as FE
participant "后端" as BE
participant "数据库" as DB

user -> FE : 输入用户名、密码并提交
activate FE
FE -> BE : 提交登录请求 (POST /login)
activate BE
BE -> DB : 查询用户信息 (User)
activate DB
DB --> BE : 用户记录
deactivate DB
BE -> BE : 校验密码、锁定与激活状态 (check_password)
BE -> DB : 查询会话配置 (SystemSetting)
activate DB
DB --> BE : 配置信息
deactivate DB
BE -> BE : 创建会话 (login_user)
BE -> DB : 查询角色权限 (get_user_permission_codes)
activate DB
DB --> BE : 权限列表
deactivate DB
BE --> FE : 返回用户信息与权限
deactivate BE
FE --> user : 登录成功，跳转首页
deactivate FE
@enduml
```
