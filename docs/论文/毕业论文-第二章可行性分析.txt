================================================================================
毕业论文 - 第二章 可行性分析（2.1～2.5）
结合项目：面向移动端的测试平台（MobTestPlatform）
================================================================================

2  可行性分析

在正式开展系统设计与开发之前，需从多个维度论证本移动端测试平台是否具备开发与实施的条件，识别可能存在的问题并判断能否得到妥善解决。本部分从技术、经济、操作与法律等方面对系统开发的可行性进行分析，为是否立项开发提供依据。


2.1  技术可行性

技术可行性主要从所用技术是否成熟、开发过程中可能遇到的技术问题是否可解决等方面进行论证。

本系统采用前后端分离架构进行开发。后端基于 Python 与 Flask 框架，Flask 为轻量级 Web 框架，文档与社区资源丰富，易于上手与扩展；使用 Flask-SQLAlchemy 进行 ORM 映射、Flask-Login 实现用户认证、Flask-SocketIO 支持实时消息推送，相关扩展均为常用成熟组件。数据库采用 MySQL，为广泛使用的关系型数据库，支持事务与复杂查询，能与 SQLAlchemy 良好配合。前端采用 Vue 3 与 Vite 构建单页应用，Vue 3 为当前主流前端框架之一，配合 Element Plus 组件库可快速搭建管理类界面；脑图编辑功能基于 simple-mind-map 等开源库实现，可在浏览器内完成用例结构的编辑与展示。AI 用例生成通过调用第三方大语言模型 API 实现，采用 HTTP 请求与异步任务方式，技术路线清晰。开发与运行环境为常见操作系统（如 Windows 10/11），使用 PyCharm、VS Code 等常用 IDE 即可完成开发，无需特殊硬件或专有软件。

综上所述，本系统所采用的技术栈均为成熟、开源或可免费使用的技术，开发所需技能在本科阶段可掌握，技术风险可控。因此，在技术上是可行的。


2.2  经济可行性

经济可行性主要从开发与运行成本是否在可接受范围内进行分析。

开发阶段方面：开发工具以免费或教育优惠为主，如 Python、Flask、Vue、MySQL 等均为开源免费；PyCharm、VS Code 等 IDE 对学生有免费或优惠方案，无需额外采购高额商业软件。开发工作由本人独立完成，不产生额外人力成本。运行与部署方面：系统可在单机或内网服务器上部署，后端（Flask）与前端（静态资源）对硬件要求不高，普通 PC 或入门级云服务器即可满足；若使用云服务器，可按需选择按量或包月方案，成本可控。AI 用例生成依赖的外部 API 按调用量计费，在毕业设计或小规模使用场景下用量有限，费用在可接受范围内。

综上，本系统的开发与运行成本较低，无需大额投入，在经济上是可行的。


2.3  操作可行性

操作可行性主要从用户是否能够方便地使用系统、是否易于学习和维护等方面进行分析。

本系统面向测试团队成员使用，界面采用常见的 Web 管理后台形式，以菜单导航、列表与表单操作为主；脑图编辑、任务执行与结果填写等流程在系统内有明确入口与提示，符合一般用户对管理系统的操作习惯。前端使用 Element Plus 等组件库，保证界面风格统一、交互一致，降低学习成本。系统不要求用户具备编程或运维能力，只需通过浏览器访问即可完成项目管理、用例维护、设备查看、任务执行与报告查看等操作。部署与维护方面，项目提供一键启动脚本（如 start.py），可在指定环境下按说明启动前后端服务；数据库采用 MySQL，使用常规备份与恢复方式即可，运维门槛较低。

因此，从用户操作与日常维护角度考虑，本系统的操作是可行的。


2.4  法律可行性

法律可行性主要从所采用的技术、数据与业务行为是否符合相关法律法规与协议要求等方面进行分析。

本系统所使用的技术组件（如 Python、Flask、Vue、MySQL 及各类开源库）均遵循其各自的开源协议（如 BSD、MIT、Apache 等），在毕业设计及教学、内部使用场景下符合协议规定的使用与引用要求。系统不涉及对第三方网站或系统的未授权爬取、破解或入侵行为；所管理的数据为测试团队自身的项目、用例、设备与执行结果等业务数据，不涉及非法采集或买卖个人数据。若接入第三方 AI 接口，需遵守该服务提供方的使用条款与调用规范，不将接口用于违规用途。整体而言，本系统的开发与使用用于学习与实践目的，符合《中华人民共和国网络安全法》等法律法规对合法、正当使用网络与数据的要求。

因此，在法律上是可行的。


2.5  可行性分析结论

可行性研究结论：可行。

可行性研究说明：从技术、经济、操作与法律四个维度进行分析可知，本移动端测试平台在技术上可采用成熟稳定的技术栈实现全部预定功能，在经济上开发与运行成本可控，在操作上便于测试人员使用与维护，在法律上符合现行法规与开源协议要求。综合以上分析，本系统具备开发与实施的条件，可行性研究通过，可进入后续需求分析与系统设计阶段。
