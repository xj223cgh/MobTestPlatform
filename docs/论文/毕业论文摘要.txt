【中文摘要】
目前测试工作中，团队普遍通过 Excel 编写和维护用例，线性形式不利于由点到面的测试设计与联想，
用例结构受模板所限难以表达路径与层级，单需求维度的分散管理难以集中筛选与复用，
执行阶段缺乏可视化任务进展与结果展示，从需求到报告各环节工具割裂、数据不通；
在移动端测试中，还面临设备调度缺少统一管理、状态跟踪依赖口头沟通、测试时需在电脑与设备间来回切换等特有痛点。
为提升测试效率与规范性、解决上述共性痛点与移动端特有痛点，本文基于前后端分离架构，
使用 Flask、MySQL 等技术开发一套移动端测试平台，将用例管理、设备管理、任务执行与报告生成统一于同一系统，
实现项目与设备统一管理、脑图形式维护用例与可视化执行及结果展示，并结合 AI 模型探索测试用例的自动生成。
实践表明，该平台能有效整合测试资源、规范执行流程，对测试团队具有较好适用性。

【Abstract】

Enterprise test teams often face fragmented processes, inconvenient case maintenance, and disconnected tools in their daily work; in mobile testing they additionally face lack of unified management for physical device scheduling, status tracking that relies on verbal communication, and frequent switching between desktop and devices. To address these issues, this graduation project develops a mobile-oriented test platform using Flask, Vue, MySQL and related technologies, integrating case management, device management, task execution, and report generation. The platform supports unified management of project workflow and of Android devices, organizes case structure in mind-map form, provides multi-dimensional filtering and visible execution and results, and explores automatic test case generation with AI models. The design has been put into practical use in the author’s internship organization; practice shows that it can effectively integrate test resources and standardize execution workflows, with good applicability for test teams.

Keywords: mobile testing; test platform; case management; Flask
