# 毕业论文数据库表说明与三线表生成提示词

用于指导生成 **Word 格式**的毕业论文「数据库设计」部分的「数据库表说明 + 三线表」，使排版与效果与参考图一致。

---

## 一、使用方式

将下方「完整提示词」复制给 AI（如 Cursor、ChatGPT、Kimi 等），并**替换【】中的占位内容**为你的实际表信息；AI 将输出可直接粘贴到 Word 或用于生成 Word 的规范内容。若需批量生成多张表，可对每张表执行一次提示词，或在一个提示词中列出多张表的【表信息】。

---

## 二、完整提示词（复制使用）

```
请根据以下要求，生成毕业论文数据库设计部分的「数据库表说明」和「三线表」内容，用于放入 Word 文档，最终效果需与学术论文规范一致。

【格式与版式要求】

1. 表前文字说明（一段话）
   - 格式：(序号)表中文名: 一句话说明该表的用途与含义，如下表X所示。
   - 示例：(5)申请信息表: 记录普通用户的房东用户申请审核信息,如下表6所示。
   - 句末用中文逗号，表序号与正文中引用一致（如表4-1、表6等）。

2. 表格标题（单独一行，表上方）
   - 格式：表X 表中文名
   - 示例：表6 申请信息表
   - 标题与表格之间不要空行过多，符合论文三线表规范。

3. 三线表样式（必须严格遵循）
   - 只有三条线：表格顶线（粗）、表头下方线（细）、表格底线（粗）。无竖线，无数据行之间的横线。
   - 表头列名（共5列）：名称 | 代码 | 主键 | 外键 | 数据类型
   - 主键、外键列：填写「是」或「否」，不要用 √/× 或 Yes/No。
   - 名称列：写中文名，可在括号内补充英文名，如：申请编号(Application ID)、用户编号(User ID)。
   - 代码列：写英文字段名（小写、下划线），如 id、home_user_id、create_time。
   - 数据类型列：写数据库类型，如 bigint、varchar、datetime，长度可写可不写（若论文规范要求写长度则保留）。

【表信息】（请替换为你要生成的表）

- 表序号（在全文中的编号）：【例如 4-1 或 6】
- 表中文名：【例如 申请信息表 / 用户表】
- 表英文名/代码（可选，用于说明）：【例如 users / application_info】
- 表用途一句话：【例如 记录普通用户的房东用户申请审核信息 / 存储系统用户的基本信息】
- 字段列表（每行一个字段，格式：中文名|英文字段名|主键是/否|外键是/否|数据类型）：
  【示例：
  申请编号|id|是|否|bigint
  用户编号|home_user_id|否|是|bigint
  身份证|id_card_path|否|否|varchar
  租赁许可证|lease_ensure_path|否|否|varchar
  创建时间|create_time|否|否|datetime
  更新时间|update_time|否|否|datetime
  】

请直接输出：
(1) 表前的一段文字说明；
(2) 表格标题；
(3) 三线表（用 Markdown 表格或清晰列出表头与每一行数据，便于我复制到 Word 后改成三线表）。
若你支持输出 .docx 或可被 Word 识别的格式，也可说明。
```

## 四、在 Word 中做成「三线表」的简要步骤

1. 先按提示词得到「表前说明 + 标题 + 表头与数据」。
2. 在 Word 中插入表格：列数 5（名称、代码、主键、外键、数据类型），行数 = 1 表头 + N 行数据。
3. 填写表头与单元格内容。
4. 设置三线：
   - 选中表格 → 表设计 → 边框：只保留 **顶部框线**（可设为 1.5 磅）、**表头行下框线**（0.5 磅）、**整表底部框线**（1.5 磅），其余框线取消。
5. 表题放在表格上方，格式为「表X 表中文名」，可设为题注或单独段落。

---

## 五、效果检查清单

- [ ] 表前有一段「(序号)表名: 用途说明,如下表X所示。」
- [ ] 表格标题为「表X 表中文名」，位于表上方。
- [ ] 表头仅 5 列：名称、代码、主键、外键、数据类型。
- [ ] 主键/外键列为「是」或「否」。
- [ ] 表格仅三条线：顶线、表头下划线、底线；无竖线、无行间线。
- [ ] 名称列含中文（可带英文括号注释），代码列为英文字段名，数据类型与设计一致。

按上述提示词与步骤即可在 Word 中复现与参考图一致的数据库表说明与三线表效果。
