# 功能界面截图目录

说明文档**仅需少量关键配图**时，使用下列文件名即可（与根目录 `README.md`「界面预览」一致）。

| 建议文件名 | 对应界面 |
|------------|----------|
| `ui-home-dashboard.png` | 首页 / 仪表盘 |
| `ui-testcase.png` | 测试用例管理（树形/列表）；也可用脑图全屏页代替以突出脑图能力 |
| `ui-device.png` | 设备管理（列表 + 本机 Agent / 操作区，尽量一屏） |

**可选扩展**：若文档需要再补登录、任务、报告等，可自行增加文件（如 `ui-login.png`），不必与本表强制一致。

在仓库根目录 `README.md` 中引用示例：

```markdown
![首页仪表盘](docs/images/ui-home-dashboard.png)
```

在 `docs/项目文档/` 下写相对路径：`../images/ui-home-dashboard.png`。
