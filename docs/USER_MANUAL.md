## 快速入门

### 什么是移动测试平台？

移动测试平台（MobTestPlatform）是一个专业的移动端测试管理系统，提供项目管理、需求管理、用例管理、设备管理、测试任务执行、报告生成等一站式测试管理能力，支持 Android 设备的 ADB 管理和投屏操作。

### 系统特点

- **一站式管理**: 覆盖项目、需求、用例、任务、报告全流程
- **设备管理**: 支持 Android ADB 设备管理、无线连接、Escrcpy 投屏
- **AI 辅助**: 支持 AI 自动生成测试用例
- **实时通信**: WebSocket 实时消息推送
- **灵活权限**: 四级角色体系 + 功能埋点权限可视化配置
- **数据可视化**: ECharts 仪表盘，直观掌握测试进度

### 第一次使用

#### 步骤 1：访问系统

在浏览器中输入系统地址，例如：`http://localhost:8081`

#### 步骤 2：登录系统

使用管理员提供的账号密码登录，或使用已绑定的 QQ 邮箱通过验证码登录。

#### 步骤 3：创建项目

进入「项目管理」页面，点击「创建项目」，填写项目信息并添加项目成员。

#### 步骤 4：管理用例

进入「用例管理」页面，创建用例文件夹和用例集，编写测试用例或使用 AI 生成用例。

#### 步骤 5：执行测试

进入「测试任务」页面，创建测试任务，关联用例和设备，执行测试并记录结果。

#### 步骤 6：查看报告

任务完成后，系统自动生成测试报告，也可在「报告管理」页面手动生成或导出报告。

## 登录与认证

### 账号密码登录

1. 在登录页面输入用户名和密码
2. 可勾选「记住我」，下次自动填充登录信息
3. 点击「登录」按钮

### QQ 邮箱验证码登录

1. 切换到「邮箱登录」选项
2. 输入已绑定的 QQ 邮箱地址
3. 点击「获取验证码」，系统发送验证码到邮箱（5 分钟有效）
4. 输入收到的验证码，点击登录

### 注册

1. 在登录页面点击「注册」链接
2. 填写用户名（3-14 字节）、手机号、真实姓名等信息
3. 设置密码并确认
4. 提交注册

### 忘记/重置密码

1. 在登录页面点击「忘记密码」
2. 输入注册时绑定的 QQ 邮箱
3. 获取邮箱验证码并验证
4. 设置新密码

### 登录失败锁定

系统设有登录安全机制，连续多次输入错误密码后账户将被临时锁定，锁定时长由管理员在「系统设置 → 安全设置」中配置。

## 首页仪表盘

登录后默认进入首页，显示数据统计仪表盘，包含：

- **概览数据**: 项目总数、用例总数、任务总数、设备总数等关键指标
- **测试进度**: 当前活跃任务的执行进度和通过率
- **统计图表**: 基于 ECharts 的数据可视化图表，展示测试趋势和分布情况

## 项目管理

### 项目列表

展示所有项目的概览信息，包括项目名称、状态、负责人、成员数量、用例统计等。支持搜索和筛选。

### 创建项目

1. 点击「创建项目」按钮
2. 填写项目信息：
   - **项目名称**: 必填，唯一
   - **项目描述**: 项目详细说明
   - **项目负责人**: 选择负责人
   - **优先级**: 高 / 中 / 低
   - **起止日期**: 项目周期
   - **文档链接**: 关联项目文档
   - **流水线链接**: 关联 CI/CD 流水线
   - **标签**: JSON 格式项目标签
3. 点击「保存」

### 项目详情

点击项目名称进入详情页，可查看：
- 项目基本信息
- 项目成员列表
- 关联的迭代
- 用例统计（总数、通过、失败、阻塞、通过率、执行进度）
- 迭代统计
- 需求统计

### 成员管理

- **添加成员**: 选择用户并分配项目角色（owner / manager / tester / viewer）
- **修改角色**: 调整成员在项目中的角色
- **移除成员**: 将成员从项目中移除

### 项目状态

| 状态 | 说明 |
|------|------|
| 未开始 (`not_started`) | 项目创建后默认状态 |
| 进行中 (`in_progress`) | 项目正在执行 |
| 已暂停 (`paused`) | 项目暂时中止 |
| 已完成 (`completed`) | 项目已结束 |
| 已关闭 (`closed`) | 项目已归档关闭 |

|------|------|
| 规划中 (`planning`) | 迭代创建后默认状态 |
| 进行中 (`active`) | 迭代正在执行 |
| 已完成 (`completed`) | 迭代已结束 |
| 已取消 (`cancelled`) | 迭代被取消 |

查看迭代下的版本需求列表、关联的测试任务及用例执行统计。

## 需求管理

### 版本需求列表

展示版本需求的列表，支持按项目、迭代、状态、优先级筛选。

### 创建需求

1. 填写需求信息：
   - **需求名称**: 必填
   - **需求描述**: 详细说明
   - **所属项目**: 必填
   - **所属迭代**: 可选，关联到某个迭代
   - **所属模块**: 可选
   - **优先级**: P0 ~ P4
   - **需求环境**: test / staging / production
   - **预估/实际工时**: 用于工时追踪
   - **分配给**: 指定负责人
   - **起止日期**: 需求周期
2. 保存

### 需求状态

| 状态 | 说明 |
|------|------|
| 新建 (`new`) | 需求创建后默认状态 |
| 进行中 (`in_progress`) | 需求正在开发/测试 |
| 已完成 (`completed`) | 需求已完成 |
| 已取消 (`cancelled`) | 需求被取消 |

### 需求与用例关联

需求可关联测试用例，在需求详情中查看已关联的用例数量和执行情况。

## 设备管理

### 设备列表

展示所有 Android 设备的信息，包括设备名称、型号、系统版本、设备 ID、连接状态和负责人。

### 设备状态说明

| 状态 | 说明 |
|------|------|
| 在线 (`online`) | 设备已连接并可用 |
| 离线 (`offline`) | 设备未连接 |
| 忙碌 (`busy`) | 设备正在执行任务 |
| 维护中 (`maintenance`) | 设备处于维护状态 |

### ADB 设备管理

系统通过 ADB（Android Debug Bridge）管理 Android 设备：

1. **USB 连接**: 通过 USB 线连接设备后自动识别
2. **无线连接**: 
   - 输入设备 IP 地址和端口
   - 点击「无线连接」按钮
   - 连接成功后设备状态变为「在线」
3. **断开连接**: 选择在线设备，点击「断开」按钮

### 投屏功能

选择在线设备，点击「投屏」按钮，通过 Escrcpy 工具在电脑上查看和操作设备屏幕。

### 设备操作

- **查看详情**: 查看设备完整信息
- **截图**: 获取当前设备屏幕截图
- **安装应用**: 向设备推送并安装 APK
- **Shell 命令**: 对设备执行 ADB Shell 命令

## 用例管理

### 树形用例库

用例管理采用树形结构组织，包含两种节点类型：

- **用例文件夹（folder）**: 用于分类组织，可无限层级嵌套
- **用例集（suite）**: 包含实际测试用例的容器

操作：
1. 左侧展示树形目录结构
2. 右键可创建文件夹、创建用例集、重命名、删除
3. 点击用例集，右侧展示该用例集下的所有用例

### 创建测试用例

1. 选择目标用例集
2. 点击「新建用例」
3. 填写用例信息：
   - **用例编号**: 可选，系统可自动生成
   - **用例名称**: 必填
   - **用例描述**: 用例说明
   - **优先级**: P0 ~ P4
   - **前置条件**: 用例执行前需满足的条件
   - **测试步骤**: 详细操作步骤
   - **预期结果**: 期望的输出结果
   - **测试数据**: 测试所需数据
4. 保存

### AI 生成用例

1. 选择目标用例集
2. 点击「AI 生成」按钮
3. 输入需求描述或功能点
4. AI 自动生成测试用例列表
5. 确认或编辑后保存

### 脑图视图

1. 选择用例集
2. 点击「脑图」按钮
3. 以思维导图形式展示用例的层级关系
4. 支持展开/折叠节点

### 导入导出

- **导入**: 支持从文件导入用例数据
- **导出**: 将用例数据导出为文件

## 用例评审

### 发起评审

1. 进入「用例评审」页面或从用例集发起
2. 选择要评审的用例集
3. 指定评审人
4. 提交评审任务

### 执行评审

1. 评审人收到评审通知
2. 进入评审任务，逐条审核用例
3. 对每条用例给出评审意见：
   - **通过（approved）**: 用例合格
   - **拒绝（rejected）**: 用例需要修改，并填写评审意见
4. 评审完成后提交整体评审结果

### 评审状态

| 任务状态 | 说明 |
|----------|------|
| 待处理 (`pending`) | 评审任务已创建，等待评审 |
| 评审中 (`in_review`) | 评审人正在审核 |
| 已完成 (`completed`) | 评审已完成 |
| 已拒绝 (`rejected`) | 评审被打回，需要修改后重新提交 |

### 评审历史

系统完整记录每次评审的历史，包括：
- 评审任务信息（发起人、评审人、时间）
- 每条用例的评审状态和意见
- 用例内容快照（评审时的用例内容副本，不随后续修改变化）
- 评审版本号

## 测试任务

### 任务类型

系统支持两种测试任务类型：

1. **用例执行任务（test_case）**: 关联测试用例集，逐条执行并记录结果
2. **设备脚本任务（device_script）**: 上传脚本文件（`.sh` / `.py`），在设备上执行

### 任务文件夹

任务按类型分别组织在独立的文件夹树中，用于分类管理。

### 创建用例执行任务

1. 点击「创建任务」按钮
2. 填写任务信息：
   - **任务名称**: 必填
   - **任务描述**: 任务说明
   - **所属项目/迭代**: 可选关联
   - **用例集**: 选择要执行的用例集
   - **执行者**: 指定执行人
   - **关联设备**: 选择测试设备
   - **优先级**: 高 / 中 / 低
   - **计划起止时间**: 任务周期
   - **相关文档链接**: 关联文档
   - **版本信息**: 关联版本号
   - **所属文件夹**: 可选，将任务归入文件夹
3. 保存

创建任务时，系统自动保存关联用例的**内容快照**，确保后续查看报告时看到的是任务创建时的用例内容。

### 创建设备脚本任务

1. 选择「设备脚本」任务类型
2. 上传脚本文件（支持 `.sh`、`.py`，最大 10MB）
3. 配置执行命令
4. 选择目标设备
5. 保存

### 执行任务

1. 打开任务详情
2. 逐条执行用例，记录执行结果：
   - **通过（pass）**: 用例验证通过
   - **失败（fail）**: 用例验证失败
   - **阻塞（blocked）**: 用例无法执行
   - **不适用（not_applicable）**: 用例不适用当前场景
3. 可填写执行备注
4. 完成所有用例后，任务状态自动更新

### 任务状态

| 状态 | 说明 |
|------|------|
| 待执行 (`pending`) | 任务创建后默认状态 |
| 执行中 (`running`) | 任务正在执行 |
| 已完成 (`completed`) | 任务执行完毕 |
| 已暂停 (`paused`) | 任务暂时中止 |

### 任务统计

每个任务自动统计：
- 通过数、失败数、阻塞数、不适用数
- 已执行数、未执行数
- 通过率

## 报告管理

### 自动生成

任务完成后，系统自动生成测试报告，报告内容包含任务完成时的数据快照，不会随任务后续修改而变化。

### 手动生成

1. 进入「报告管理」页面
2. 选择任务，点击「生成报告」
3. 报告自动创建

### 报告内容

- **报告摘要**: 任务名称、项目名称、迭代信息、完成时间
- **执行统计**: 通过数、失败数、阻塞数、不适用数、通过率
- **用例明细**: 每条用例的执行结果和备注
- **任务信息快照**: 用例集名称、需求名称、迭代名称等

### 报告类型

- **用例执行报告（test_case）**: 用例执行任务的报告
- **设备脚本报告（device_script）**: 设备脚本任务的报告

### 导出报告

支持将报告导出为：
- **Word 文档**: 适合归档和分享
- **Excel 表格**: 适合数据分析

## 消息通知

### 实时推送

系统通过 WebSocket（Socket.IO）实现消息实时推送，新消息到达时：
- 顶部导航栏通知图标显示未读数量
- 弹出消息提醒

### 消息中心

进入「消息中心」查看所有通知消息：

- **消息列表**: 展示所有消息，支持按类型筛选
- **已读/未读**: 点击消息标记为已读，支持全部标记已读
- **置顶**: 重要消息可置顶显示
- **删除**: 软删除不需要的消息

### 通知类型

系统在以下场景自动发送通知：
- 评审任务分配
- 评审完成/打回
- 任务状态变更
- 成员变更
- 系统公告

## 用户管理

> 需要管理员（manager）或超级管理员（super）权限

### 用户列表

展示所有系统用户，包括用户名、真实姓名、手机号、邮箱、部门、角色、状态等信息。支持搜索和筛选。

### 添加用户

1. 点击「添加用户」按钮
2. 填写用户信息：
   - **用户名**: 3-14 字节，唯一
   - **真实姓名**: 必填
   - **手机号**: 11 位手机号，唯一
   - **邮箱**: QQ 邮箱（可选，用于邮箱登录和找回密码）
   - **部门**: 所属部门
   - **性别**: 男 / 女 / 其他

### 编辑用户

选择用户，修改用户信息和角色。

### 禁用/启用用户

管理员可禁用或启用用户账户。被禁用的用户无法登录系统。

管理员可为用户重置密码。

### 角色说明

| 角色 | 标识 | 权限范围 |
|------|------|----------|
| 超级管理员 | `super` | 拥有所有权限，可管理系统设置和权限配置 |
| 管理员 | `manager` | 可管理项目、用户，执行大部分操作 |
| 测试人员 | `tester` | 可执行测试任务、管理用例 |
| 普通成员 | `admin` | 基础查看和参与权限 |

## 权限配置

> 需要超级管理员（super）权限

### 功能埋点权限

系统通过功能埋点（permission_code）控制前端菜单和按钮的显隐。每个角色可配置一组可用的功能埋点编码。

### 配置方式

1. 进入「权限配置」页面
2. 选择角色（super / manager / tester / admin）
3. 勾选该角色可使用的功能项
4. 保存配置

配置生效后，对应角色的用户前端界面会自动隐藏无权限的菜单和按钮。

## 系统设置

> 需要管理员权限

### 安全设置

- **登录失败锁定**: 配置连续登录失败多少次后锁定账户
- **锁定时长**: 账户锁定持续时间
- **会话超时**: 登录会话过期时间（默认 24 小时）

### 分页设置

- **默认每页条数**: 列表页默认显示的数据行数（默认 20）
- **单页最大条数**: 允许的最大每页数量（默认 100）

### 自动报告设置

- 配置任务完成后是否自动生成报告

### 系统设置存储

系统设置以键值对形式存储在 `system_settings` 表中，支持通过管理后台可视化修改。

## 常见问题

### 登录相关

**Q: 账户被锁定怎么办？**

A: 连续输入错误密码超过限制次数后账户会被临时锁定。等待锁定时间过后自动解锁，或联系管理员手动解锁。

**Q: 忘记密码怎么办？**

A: 如果已绑定 QQ 邮箱，可在登录页点击「忘记密码」，通过邮箱验证码重置密码。如果未绑定邮箱，请联系管理员重置密码。

### 设备相关

**Q: 设备连接失败怎么办？**

A: 请按以下步骤排查：
1. 确认 USB 线连接正常或无线连接 IP 地址正确
2. 确认设备已开启 USB 调试模式
3. 确认 ADB 服务正常运行
4. 检查防火墙是否阻断了 ADB 端口

**Q: 设备经常断线？**

A: 可能的原因：
1. USB 线松动或质量差
2. 无线连接网络不稳定
3. 设备进入休眠状态（建议开启「开发者选项 → 不锁定屏幕」）

**Q: 投屏功能无法使用？**

A: 确认已安装 Escrcpy 工具，且设备处于在线状态。

### 用例相关

**Q: AI 生成用例不准确？**

A: AI 生成的用例仅作为参考，建议根据实际需求进行修改和补充。输入的需求描述越详细，生成的用例质量越高。

### 报告相关

**Q: 报告数据与当前任务不一致？**

A: 报告在生成时保存了数据快照，后续对任务或用例的修改不会影响已生成的报告。如需更新，可重新生成报告。

### 权限相关

**Q: 某些功能看不到？**

A: 系统基于角色和功能埋点控制权限，不同角色看到的菜单和按钮不同。如需开通权限，请联系超级管理员在「权限配置」中修改。
