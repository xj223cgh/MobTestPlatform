# 移动端测试平台——项目设计背景与目标

在软件测试工作中，我注意到测试团队普遍依赖 Excel 或 Xmind 等管理用例，每次版本迭代都需要花费大量时间手动维护；特别是涉及移动端测试，通常我们的真机设备缺少统一管理，借用和状态跟踪全靠口头沟通，工作时需要在工作电脑和设备上来回切换；从需求到报告各个环节使用不同工具，数据无法互通；手写用例也很耗时，在测试环节的时间占比比较大的一些痛点。

基于以上问题，我以此为课题做了这个毕业设计。平台的目标是把用例管理、设备管理、测试执行和报告生成整合到一起，打通整个测试流程；同时引入大语言模型，支持根据需求文档自动生成测试用例，减少重复性工作，对测试流程进行提效；另外加入了角色权限体系，让平台能适应多人协作的实际使用场景。
