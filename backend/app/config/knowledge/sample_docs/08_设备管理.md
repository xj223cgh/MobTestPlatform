# 设备管理模块

## 设备 CRUD

- 设备属性：设备名称、品牌、型号、系统版本、分辨率、设备序列号（serial number）、状态、分配人、备注
- 设备状态：online / offline / busy / maintenance
- 支持手动录入和 Agent 自动发现两种方式

## ADB 设备发现

- 前提：用户已绑定 Agent，Agent 在线
- Agent 运行 `adb devices` 获取已连接设备列表
- 平台拉取 Agent 的设备列表，用户选择后录入到平台

## ADB 指令下发

- 平台内置常用 ADB 命令模板（安装应用、截图、录屏、获取日志等）
- 用户选择设备后下发指令，Agent 在本地执行
- 命令执行结果异步回传到平台

## 批量操作

- 批量分配：将多台设备分配给某个用户
- 批量状态更新：如批量标记为 maintenance

## 计划任务

- 定时调度：设置 cron 表达式，Agent 在指定时间自动执行任务
- 例如：每晚 2 点自动运行回归测试脚本

## 投屏

- 基于 scrcpy 技术，通过 Electron 封装的 escrcpy 工具实现本地投屏
- 平台提供下载入口和配置指引
- 仅支持 Android 设备

## Agent 桥接

### Agent 注册

- Agent 是安装在测试机上的客户端程序（Python 打包为可执行文件）
- 首次启动时向平台注册，获取唯一 agent_id
- 注册后生成绑定码，用户在平台输入绑定码完成 Agent 与账号绑定

### 绑定与解绑

- 一个用户可绑定多个 Agent
- 一个 Agent 只能绑定一个用户
- 解绑后 Agent 变为未绑定状态，不再响应平台调度

### 心跳保活

- Agent 每 30 秒向平台发送心跳请求
- 平台记录最近心跳时间，超过 90 秒未收到心跳则标记为 offline
- 前端设备列表实时展示 Agent 在线/离线状态

### Agent 下载

- 平台系统设置中提供 Agent 可执行文件下载入口
- 支持 Windows / macOS（Linux 暂不支持）
