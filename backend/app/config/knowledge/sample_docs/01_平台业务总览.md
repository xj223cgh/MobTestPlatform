# MobTestPlatform 业务总览

## 产品定位

MobTestPlatform 是一个面向移动端测试团队的 Web 测试管理平台，核心目标是覆盖从"需求→用例→执行→报告"的完整测试闭环，并提供设备管理和 AI 辅助生成用例能力。

## 技术栈

- 前端：Vue 3 + Element Plus + Vite，脑图编辑器基于自研组件
- 后端：Flask + SQLAlchemy + MySQL，Socket.IO 实时通信
- 设备侧：本机 Agent（Python 可执行文件），通过 ADB 操控 Android 设备
- AI：SiliconFlow 大模型 API，支持 RAG 知识库检索

## 用户角色体系

平台采用四级角色：
- **超级管理员（super）**：全局管理，可操作系统设置、用户管理、权限配置
- **项目管理员（manager）**：项目内全权限，可管理成员、迭代、需求
- **测试工程师（tester）**：可创建/编辑用例、执行任务、发起评审
- **只读成员（admin）**：仅查看，不可编辑

角色权限通过 `role_permissions` 表进行细粒度配置，支持按功能点开关。

## 核心业务流程

```
项目创建 → 迭代规划 → 需求录入
                          ↓
              用例编写（脑图/手工/AI生成）
                          ↓
                      用例评审
                          ↓
              测试任务创建（关联用例集，锁定快照）
                          ↓
                手工执行 / 设备脚本执行
                          ↓
                     测试报告生成
```

## 模块清单

| 模块 | 核心功能 |
|------|---------|
| 认证与账户 | Cookie 会话登录、忘记密码（邮箱验证码）、个人中心 |
| 首页看板 | 平台统计（项目/用例/设备/任务数）、活动流、趋势图、设备状态 |
| 项目管理 | 项目 CRUD、成员管理、迭代管理、需求管理 |
| 用例管理 | 用例树（文件夹+用例集）、用例 CRUD、脑图编辑器、版本管理、AI 用例生成、批量操作、回收站、标签/标记、Excel 导入 |
| 用例评审 | 发起评审、评审中心（待处理/进行中/已完成）、逐条通过/驳回、评审历史 |
| 测试任务 | 任务文件夹、任务 CRUD、用例快照、手工逐条执行（通过/失败/阻塞/跳过）、执行统计、设备脚本异步调度 |
| 测试报告 | 自动生成、报告详情（汇总+明细）、Word/Excel 导出、批量删除 |
| 设备管理 | 设备 CRUD、ADB 发现、ADB 指令下发、投屏（scrcpy）、Agent 注册/绑定/心跳 |
| 系统管理 | 用户 CRUD、角色权限配置、全局设置（平台名称/Logo）、AI 参数配置 |
| 消息中心 | 站内通知（Socket.IO 实时推送）、已读管理、置顶、清空 |

## 数据关系概要

- 一个项目包含多个迭代，一个迭代包含多条需求
- 一个项目下有多级文件夹和用例集（树形结构），用例集下有用例
- 测试任务关联用例集，创建时锁定用例快照
- 评审任务关联用例集，评审人对用例逐条审批
- 任务执行完成后自动生成报告
- 设备通过 Agent 桥接管理，Agent 需用户绑定后才能使用
