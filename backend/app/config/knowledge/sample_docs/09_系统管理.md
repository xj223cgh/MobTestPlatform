# 系统管理模块

## 用户管理

- 超级管理员可对系统用户执行 CRUD
- 用户字段：用户名（唯一）、密码、真实姓名、邮箱（唯一）、手机号、部门、角色、头像、状态（active/inactive）
- 新增用户时指定初始密码，系统以哈希形式存储
- 停用用户：将 status 设为 inactive，该用户无法登录但数据保留
- 管理员可重置任意用户密码

## 角色权限

### 四级角色

| 角色 | 说明 |
|------|------|
| super（超级管理员） | 系统级全部权限，不受项目限制 |
| manager（项目管理员） | 项目内全部权限，可管理成员和设置 |
| tester（测试工程师） | 创建/编辑用例、执行任务、发起评审 |
| admin（只读成员） | 仅查看权限，不可编辑/删除 |

### 功能点权限

权限存储在 `role_permissions` 表中，结构：
- role_id：关联角色
- permission_code：功能点编码（如 `project:create`、`case:delete`）
- is_allowed：是否允许

功能点覆盖范围：菜单访问、按钮操作、API 接口

### 权限配置界面

- 可视化展示所有功能点，按模块分组
- 管理员可通过勾选开关调整各角色的权限
- 修改后即时生效

## 系统设置

### 全局配置

- 平台名称：自定义显示名称
- 平台 Logo：上传替换默认 Logo
- 站点地址：配置平台访问 URL

### AI 参数配置

- API Base URL：大模型 API 地址
- API Key：身份凭证
- Model：模型选型（如 Qwen/Qwen3-8B）
- Embedding Model：嵌入模型选型
- Vision Model：视觉模型选型
- Max Tokens：最大输出 Token 数
- Temperature：生成随机性参数
