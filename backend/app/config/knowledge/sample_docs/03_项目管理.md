# 项目管理模块

## 项目

- 项目是平台最顶层的业务实体，所有用例、任务、报告均挂在项目下
- 项目属性：名称（唯一）、描述、状态（planning/in_progress/completed）、标签（JSON 数组）、优先级、文档 URL、流水线 URL、起止日期
- 项目创建者自动成为 Owner
- 删除项目会级联清理下属迭代、需求、用例集、任务等数据
- 项目列表支持按名称搜索、分页展示

## 成员管理

- 项目成员从系统用户中选取，分配项目内角色：owner / manager / tester
- Owner 不可被移除，且每个项目有且仅有一个 Owner
- 非项目成员不能访问该项目的任何资源
- 成员列表展示：用户名、角色、加入时间

## 迭代管理

- 迭代属于项目，代表一个版本周期
- 迭代属性：名称、版本号、目标、状态（planning/active/completed）、起止日期
- 迭代关联需求，需求关联用例，形成覆盖链路
- 迭代统计：需求覆盖率 = 有用例的需求数 / 总需求数，执行进度 = 已执行用例数 / 总用例数
- 支持复制迭代（复制基本信息，不复制用例数据）

## 需求管理

- 需求属于迭代，描述一个功能点或变更
- 需求属性：名称、描述、模块、状态（new/in_progress/completed）、优先级（P0-P4）、预估工时、实际工时、指派人、环境
- 需求可关联用例集，用于追踪需求覆盖情况
- 支持按优先级排序、按状态筛选
