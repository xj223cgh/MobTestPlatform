# 认证与账户模块

## 登录与登出

- 采用 Cookie + Session 会话机制，前端请求带 `withCredentials`
- 登录入参：用户名 + 密码，后端使用 werkzeug 密码哈希校验
- 登录成功后返回用户信息（用户名、角色、头像等），前端存入 Pinia 状态管理
- 登出时清除服务端 Session 和客户端 Cookie
- Session 超时时间可在系统设置中配置，默认 24 小时
- 已停用用户（status=inactive）无法登录

## 忘记密码

- 流程：输入邮箱 → 发送 6 位验证码到绑定邮箱 → 验证码校验通过后重置密码
- 验证码有效期 10 分钟
- 邮件通过 SMTP（QQ 邮箱）发送
- 用户必须已绑定邮箱才能使用此功能

## 个人中心

- 可修改：真实姓名、手机号、部门、性别
- 头像上传：支持 jpg/png，限制 2MB
- 修改密码：需输入旧密码 + 新密码 + 确认密码
- 个人设置：通知偏好（是否接收邮件通知）、界面偏好

## 业务规则

- 用户名全局唯一
- 手机号格式校验：11 位数字
- 密码存储：werkzeug 哈希，不存明文
- 超级管理员可重置任意用户密码，普通用户只能修改自己的
