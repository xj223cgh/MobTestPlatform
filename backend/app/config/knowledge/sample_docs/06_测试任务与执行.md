# 测试任务与执行模块

## 任务管理

### 任务文件夹

- 任务文件夹用于对测试任务进行分组管理
- 支持创建、重命名、删除

### 任务 CRUD

- 创建任务：填写任务名称、描述、优先级、关联用例集、指派执行人、截止日期
- 关联用例集：任务创建时从项目下的用例集中选择，创建后锁定用例快照
- 用例快照：任务关联的用例在创建时被冻结，后续用例编辑不影响已创建任务中的用例版本

### 任务状态

- pending：待执行
- in_progress：执行中
- completed：已完成
- blocked：被阻塞

## 手工执行

测试人员在执行界面逐条执行用例：

1. 查看用例信息（前置条件、步骤、预期结果、测试数据）
2. 按步骤操作后标记结果：
   - **pass**：通过
   - **fail**：失败（可填写缺陷描述、截图）
   - **blocked**：被阻塞（填写阻塞原因）
   - **skip**：跳过（填写跳过原因）
3. 执行进度实时更新

### 执行控制

- 开始执行：状态从 pending → in_progress
- 暂停执行：保留当前进度，可继续
- 完成执行：所有用例标记完毕，状态 → completed

### 执行统计

- 总用例数、已执行数、未执行数
- 通过率 = pass / 已执行数
- 用例结果分布：pass / fail / blocked / skip
- 按优先级统计执行情况

## 设备脚本执行

- 选择已绑定的在线设备
- 上传/选择自动化脚本
- 异步调度到设备侧 Agent 执行
- 执行结果回传到平台，写入任务执行记录
