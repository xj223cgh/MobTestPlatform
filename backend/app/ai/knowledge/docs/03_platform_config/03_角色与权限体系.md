# 角色与权限体系

## 四级角色定义

| 角色 | 编码 | 说明 | 项目范围 |
|------|------|------|---------|
| 超级管理员 | super | 系统级全部权限，不受项目限制 | 全局 |
| 项目管理员 | manager | 项目内全部权限，可管理成员和设置 | 项目内 |
| 测试工程师 | tester | 创建/编辑用例、执行任务、发起评审 | 项目内 |
| 只读成员 | admin | 仅查看权限，不可编辑/删除 | 项目内 |

## 权限控制规则

- 超级管理员拥有全部权限，不受上述配置限制
- 权限存储在 `role_permissions` 表，按 `(role_id, permission_code)` 配置
- 前端通过 `v-if` 控制按钮/菜单显隐
- 后端接口通过装饰器校验权限
- 未配置权限的功能点默认不限制访问

## 测试关注点

- 各角色权限边界是否正确（重点：tester 和 admin 的区别）
- 前端按钮隐藏后，直接调用后端接口是否仍然被拦截
- 权限配置修改后是否即时生效
- 跨项目数据隔离是否有效
