# 历史问题与经验总结

## 认证与会话

| 问题 | 根因 | 测试要点 |
|------|------|---------|
| Session 过期后前端未跳转登录页 | 前端未统一处理 401 响应 | 验证 Session 超时后各页面行为 |
| 多标签页登出不同步 | Cookie 清除但其他标签页未感知 | 多标签页场景登出/登入切换 |
| 并发请求在 Session 过期临界点 | 后端 Session 校验与续期竞态 | Session 临过期时发起并发请求 |
| 密码重置后旧 Session 仍有效 | 重置密码未清除已有 Session | 重置密码后验证旧会话是否失效 |

## 数据一致性

| 问题 | 根因 | 测试要点 |
|------|------|---------|
| 删除项目后用例集残留 | 级联删除遗漏关联表 | 删除父实体后查询所有子实体 |
| 用例数统计与实际用例数不一致 | suite.case_count 未同步更新 | 增删用例后检查 case_count |
| 脑图数据与用例列表不同步 | 脑图保存和用例保存是两个独立操作 | 脑图修改后检查用例列表数据 |
| 回收站还原后用例编号重复 | 还原时未重新检查编号唯一性 | 删除-新建同编号-还原的序列 |

## 并发与竞态

| 问题 | 根因 | 测试要点 |
|------|------|---------|
| 两人同时编辑同一用例 | 无乐观锁或版本号机制 | 两用户同时打开编辑后分别保存 |
| AI 生成用例时用户删除用例集 | 异步任务未检查用例集状态 | 生成期间删除/修改用例集 |
| 批量操作部分成功部分失败 | 事务粒度过大或过小 | 批量操作中插入不合法数据 |
| Socket.IO 重连后消息丢失 | 重连期间产生的通知未补推 | 断网-重连后检查通知完整性 |

## 权限控制

| 问题 | 根因 | 测试要点 |
|------|------|---------|
| 前端按钮隐藏但接口无鉴权 | 仅前端控制，后端未加权限校验 | 用低权限角色直接调用高权限接口 |
| 跨项目可访问他人用例 | 接口未校验项目归属 | 构造其他项目的用例 ID 进行操作 |
| 角色变更后权限不立即生效 | 权限缓存未及时刷新 | 修改角色后立即验证新权限 |

## 文件与上传

| 问题 | 根因 | 测试要点 |
|------|------|---------|
| 上传超大文件导致 OOM | 未限制文件大小 | 上传超过限制的文件 |
| Excel 导入特殊字符乱码 | 编码检测不准确 | 导入含中文/特殊字符的 Excel |
| 头像上传非图片格式未校验 | 仅校验扩展名未校验 MIME | 修改扩展名上传非图片文件 |
| 并发上传同名文件覆盖 | 文件名冲突未处理 | 两用户同时上传同名头像 |

## AI 用例生成

| 问题 | 根因 | 测试要点 |
|------|------|---------|
| 长文档生成超时 | Map-Reduce 分段过多或模型响应慢 | 超过 10000 字的需求文档 |
| AI 返回非法 JSON | 模型输出包含 markdown 标记或截断 | 检查 JSON 解析降级和重试逻辑 |
| 生成用例优先级全是 P1 | 提示词对优先级分布引导不足 | 统计生成结果的优先级分布 |
| 知识库检索结果与需求无关 | embedding 质量或阈值设置不当 | 检查 RAG 上下文的相关性 |
