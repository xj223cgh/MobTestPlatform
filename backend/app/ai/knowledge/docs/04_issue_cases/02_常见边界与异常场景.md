# 常见边界与异常场景

## 输入类边界

### 文本输入
| 场景 | 测试值 | 关注点 |
|------|--------|--------|
| 空值 | `""` / `null` / 仅空格 | 是否正确拦截，提示信息是否准确 |
| 最大长度 | 字段定义的 max_length 值 | 是否截断、是否报错 |
| 超长输入 | max_length + 1 | 前端是否限制、后端是否校验 |
| 特殊字符 | `<script>alert(1)</script>` | XSS 防护 |
| SQL 注入 | `'; DROP TABLE users; --` | SQL 注入防护 |
| Emoji | `😀🎉` | 数据库编码是否支持 |
| 前后空格 | `  test  ` | 是否自动 trim |
| 富文本标签 | `<b>bold</b>` | 是否正确转义 |

### 数值输入
| 场景 | 测试值 | 关注点 |
|------|--------|--------|
| 零 | `0` | 是否被当作"空"处理 |
| 负数 | `-1` | 不应为负数的字段是否校验 |
| 小数 | `3.14` | 整数字段是否拦截小数 |
| 极大值 | `999999999` / `MAX_INT` | 是否溢出 |
| 非数字 | `abc` / `12abc` | 类型校验 |

### 文件上传
| 场景 | 测试值 | 关注点 |
|------|--------|--------|
| 空文件 | 0 字节文件 | 是否提示"文件为空" |
| 超大文件 | 超过限制的文件 | 是否有大小限制提示 |
| 错误格式 | 修改扩展名的文件 | 是否校验 MIME type |
| 中文文件名 | `测试文件.xlsx` | 文件名编码处理 |
| 特殊文件名 | `test (1).xlsx` / `test&file.xlsx` | 特殊字符处理 |

## 列表与分页

| 场景 | 关注点 |
|------|--------|
| 空列表 | 是否显示"暂无数据"提示 |
| 仅 1 条数据 | 分页是否正常 |
| 刚好满一页 | 是否显示分页控件 |
| 超过一页 | 翻页后数据是否正确 |
| 最后一页仅 1 条 | 删除后是否自动跳转前一页 |
| pageSize 非法值 | `pageSize=0` / `pageSize=-1` |
| page 超出范围 | `page=999999` |

## 并发与时序

| 场景 | 关注点 |
|------|--------|
| 双击提交 | 是否重复创建数据 |
| 同时编辑同一对象 | 后保存的是否覆盖前者 |
| 操作已被删除的对象 | 打开详情页后他人删除该对象 |
| 异步任务进行中操作关联数据 | AI 生成用例期间删除用例集 |
| 网络中断后重试 | 是否产生重复数据 |

## 状态流转

| 场景 | 关注点 |
|------|--------|
| 合法流转 | 每种状态是否只能流转到允许的下一状态 |
| 非法流转 | 直接调接口跳过中间状态是否被拦截 |
| 回退 | 是否支持状态回退，回退后数据是否一致 |
| 终态操作 | 已完成/已删除的对象是否可再次编辑 |

## 网络与环境

| 场景 | 关注点 |
|------|--------|
| 弱网环境 | 请求超时是否有友好提示 |
| 断网后恢复 | 页面数据是否自动刷新 |
| 后端服务重启 | Session 是否保持 |
| 数据库连接池耗尽 | 是否有降级处理 |
