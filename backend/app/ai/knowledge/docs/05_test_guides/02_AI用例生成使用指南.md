# AI 用例生成使用指南

## 功能概述

AI 用例生成功能基于大语言模型（LLM），根据用户输入的需求文档自动生成功能测试用例。
支持 RAG（检索增强生成）从知识库获取业务背景，提升用例质量。

## 使用流程

```
选择用例集 → 粘贴/上传需求文档 → 发起生成 → 后台异步处理 → 用例入库
                                                    ↓
                                          可选：需求文档存入知识库
```

## 输入要求

### 需求文档格式
- 支持直接粘贴文本内容
- 支持上传 .txt / .md / .docx 文件
- 支持上传图片（需配置 Vision 模型）
- .docx 文件中的嵌入图片会自动提取识别

### 需求文档质量建议
- 功能描述越详细，生成的用例质量越高
- 包含业务规则、输入校验规则有助于生成更准确的异常用例
- 包含角色权限说明有助于生成权限测试用例
- 建议每次只输入一个功能模块的需求，避免过于宽泛

## 生成策略

### 短文档模式（< 3000 字）
- 一次性将全部内容发给 AI
- 适合单个功能点或小模块的需求

### 长文档模式（≥ 3000 字）
- 自动启用 Map-Reduce 策略
- 文档按标题和段落拆分为多个片段
- 每个片段独立生成用例
- 最终合并并去重

### 知识库增强（RAG）
- 生成前自动检索知识库中的相关文档
- 知识库内容作为"业务背景参考"注入提示词
- 仅供参考，不作为用例生成的直接依据

## 生成结果

### 用例字段
每条生成的用例包含：
- 用例编号（自动生成，格式：项目缩写-版本号-需求缩写-序号）
- 用例名称
- 用例描述
- 优先级（P0-P4）
- 前置条件
- 测试步骤
- 预期结果
- 测试数据

### 输出方式
- 生成的用例自动写入关联的用例集
- 同步生成脑图节点
- 同步导出 Excel 文件到 `ai/workspace/outputs/excel/` 目录

## 调试模式

开启调试模式（debugMode=true）时：
- 用例正常入库
- 需求文档不自动存入知识库
- 适合测试和验证阶段使用

## 知识库管理

### 自动存入
- 正常模式下，需求文档在生成完成后自动存入知识库
- 供后续生成任务的 RAG 检索使用

### 手动存入
- 通过「存入知识库」按钮手动触发
- 文档内容需不少于 50 字

### 批量导入
- 通过 `load_knowledge.py` 脚本批量导入知识文档
- 支持按分类目录自动打标签

## 常见问题

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| 生成超时 | 文档过长、模型响应慢 | 缩短文档或切换更快的模型 |
| 用例质量不佳 | 需求文档描述模糊 | 补充详细的业务规则和校验规则 |
| 优先级分布不合理 | 提示词引导不足 | 在需求中标注功能重要性 |
| 生成失败（JSON错误）| 模型输出格式异常 | 系统会自动重试一次 |
| 知识库检索无结果 | 知识库为空或无相关文档 | 导入业务知识文档 |
