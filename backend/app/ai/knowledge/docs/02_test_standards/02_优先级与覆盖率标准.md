# 优先级与覆盖率标准

## 优先级分配标准

| 优先级 | 适用场景 | 建议占比 | 回归必测 |
|--------|---------|---------|---------|
| P0 | 核心业务流程（登录、创建项目、创建用例等） | 10-15% | 是 |
| P1 | 重要业务路径（编辑、删除、列表查询、状态流转） | 25-35% | 是 |
| P2 | 异常场景、边界条件、输入校验 | 30-40% | 视风险 |
| P3 | 次要功能、提示信息、显示样式 | 15-20% | 否 |
| P4 | 体验优化、UI细节、极端场景 | 0-5% | 否 |

## 优先级判断规则

### P0 判断条件（满足任一）
- 功能不可用导致用户无法完成核心任务
- 数据丢失或数据一致性问题
- 安全漏洞（未授权访问、SQL注入等）
- 系统崩溃或服务不可用

### P1 判断条件（满足任一）
- 重要功能的主要路径失败
- 业务逻辑错误但有替代方案
- 数据展示错误影响用户决策
- 权限控制失效

### P2 判断条件（满足任一）
- 异常输入未正确校验
- 边界值处理不当
- 非核心功能异常
- 错误提示不准确

### P3/P4 判断条件
- 文案错误、排版问题
- 交互体验不佳
- 极端环境下的兼容问题

## 覆盖率要求

### 功能覆盖维度

| 维度 | 权重 | 说明 |
|------|------|------|
| 正常流程 | 30% | 核心业务路径的正向验证 |
| 异常流程 | 25% | 错误输入、网络异常、服务降级、并发冲突 |
| 边界条件 | 20% | 最大值、最小值、空值、特殊字符、超长输入 |
| 权限控制 | 10% | 不同角色（super/manager/tester/admin）的操作权限 |
| 数据一致性 | 10% | 并发操作、重复提交、级联删除、数据联动 |
| 兼容与环境 | 5% | 浏览器兼容、分辨率适配、网络环境 |

### 需求覆盖率指标
- 每个需求功能点至少有 1 条正常流程用例
- 每个输入字段至少有正常值、空值、边界值 3 条用例
- 涉及权限的功能至少覆盖 2 种角色
- 涉及状态流转的功能至少覆盖正常流转 + 1 种异常流转

### 回归覆盖率
- P0 + P1 用例 100% 回归
- P2 用例视修改影响范围选择性回归
- 每次迭代新增/修改的功能点 100% 覆盖
